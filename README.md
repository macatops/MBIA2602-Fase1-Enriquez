## Descripción
Proyecto académico que consiste en el desarrollo de un chatbot basado en reglas para orientar a empleados y agentes de Seguros del Norte sobre documentación, procedimientos operativos y uso de una plataforma digital.

## Herramientas utilizadas
- Python 3.10 o superior
- NLTK
- Pandas
- Google Colab

## Funcionamiento
El chatbot procesa los mensajes del usuario, identifica intenciones mediante reglas y devuelve respuestas predefinidas. También contempla consultas desconocidas, orientación ante fallas técnicas y finalización mediante la palabra `salir`.

## Instrucciones de ejecución
1. Abrir el archivo `.ipynb` en Google Colab.
2. Ejecutar las celdas 1 a 5 en orden.
3. Ejecutar la celda 6 para iniciar una conversación.
4. Escribir `salir` para finalizar.
5. Ejecutar la celda 7 para revisar las pruebas automáticas.

## Limitaciones
El chatbot depende de las intenciones y ejemplos registrados. Puede presentar dificultades con errores ortográficos o consultas que incluyen varios temas.
